# Knowledge source files

Add manually supplied JSON source documents here. See [the source format and ingestion guide](../../../../docs/announcement-routing.md). These are durable sources for the future shared knowledge ingestion and vector index, not a separate retrieval system.

Use `manual/<stable-key>/<revision>.json` for immutable manual versions. Extraction writes only `extracted/<record_id>/<version_id>/source.json`. No example production content is supplied.
